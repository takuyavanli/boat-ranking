# ボートレースDX

日付・会場・レースを選ぶと、出走6艇を「得点率」「平均ST」「コース別3連対率」で並べて表示するアプリです。

表示される内容は次のとおりです。

- 買い目の目安（3連単の本線4点・穴目4点）
- 総合順位（得点率・平均ST・コース別3連対率の順位の合計。「得点率を2倍重視」にも切り替えられます）
- 着順の目安ラベル（★1着候補・1〜2着候補・2〜3着候補・3着候補・消し候補）と「合計点の見方」の表
- 得点率（今節・前節・合算と、それぞれの着順）
- 平均ST（今節・前節）
- コース別3連対率（今回の枠と同じコースでの3着以内率と1着率。公式サイトの選手データ）
- レース結果（「結果を見る」を押したときだけ、3連単の着順と払戻金を表示）

## ファイル

| ファイル | 役割 |
|---|---|
| `app.py` | 画面（Streamlit） |
| `boat_core.py` | データの取得と計算 |
| `lzh.py` | 公式データ（LZH形式）の解凍 |
| `requirements.txt` | 必要なライブラリ |
| `README.md` | この説明 |
| `.streamlit/config.toml` | 画面の色の設定（iPhoneのダークモードでも白・水色のまま表示） |

`.streamlit` は名前が「.」で始まるので、MacのFinderでは表示されません。

## 使い方A：スマホからいつでも使う（無料のStreamlit Community Cloud）

詳しい手順は「ボートレースDX_Mac手順.pdf」にあります。

1. GitHub（github.com）でアカウントを作り、リポジトリ `boat-ranking` を作ります（Public）。
2. 上の表のうち、`.streamlit` 以外の5ファイルをアップロードします。
3. GitHubの「Add file」→「Create new file」で `.streamlit/config.toml` を作り、`config.toml` の中身を貼り付けます。
4. share.streamlit.io にGitHubでサインインし、GitHubアカウントをつなぎます。
5. 「Create app」で、Repository に `ユーザー名/boat-ranking`、Main file path に `app.py` を指定して「Deploy」を押します。
6. 発行されたURLをスマホで開き、ホーム画面に追加します。

## 使い方B：自分のMacだけで使う

1. Python をインストールします（python.org の最新版でOK）。
2. このフォルダでターミナルを開き、次を実行します。

```
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

3. ブラウザが開きます。開かない場合は http://localhost:8501 を開いてください。

## 計算のルール

- 着順点は 1着10・2着8・3着6・4着4・5着2・6着1 です。
- 転覆・落水・失格・F・L は0点で走数に含め、欠場は走数から除きます。
- 今節は、選んだレースより前に終わったレースだけを使います。
- 前節は、今節の初日より前で最後に走った節です（公式の日別競走成績データから自動で探します）。
- 平均STは F・L・欠場を除いて計算し、小数第2位で四捨五入して表示します。順位も表示と同じ桁で付けるので、表示が同じ数字なら同順位です。
- コース別3連対率は、今回の枠番と同じコースでの成績です。前付けなどで枠とコースが変わった場合は反映されません。また、過去の日付のレースを選んだときも、今の時点の数字を使います。
- 総合順位は「得点率の順位＋STの順位＋コースの順位」が小さい順です。「得点率を2倍重視」では得点率の順位を2倍にして足します。同点の場合は、得点率が上の選手を上にします。

## 目安ラベルの決め方

10/23・10/24の全会場336レースで、合計点（3つを同じ重み）と実際の着順を集計した結果から決めています。

| ラベル | 1号艇 | 2〜6号艇 |
|---|---|---|
| 1〜2着候補 | 11点以下 | — |
| 2〜3着候補 | 12〜16点 | 7点以下 |
| 3着候補 | — | 8〜11点 |
| 消し候補 | 17点以上 | 12点以上 |

「得点率を2倍重視」を選んでいるときも、ラベルは同じ重みの合計点で判定します。

### ★1着候補（まくり型）

2〜4号艇で、平均ST（今節＋前節）が内側の艇全員より0.02秒以上早く、合計点（同じ重み）が7点以下の艇です。上の表より優先して「★1着候補」と表示します。

10/21〜10/24の648レースで、1着31%・2連対61%・3連対76%でした（2〜6号艇全体は1着9%）。10/23・24で条件を考え、10/21・22で同じくらいの1着率になることを確認しています。この艇がいるレースでは、1号艇の1着率が58%から41%に下がります。

どのラベルも数日分の集計から決めた目安です。

## 買い目の目安（3連単）

画面で「8点ずつ」「4点ずつ」を切り替えられます。相手は、頭を除いた総合順位の上位から選びます。

- 本線の頭：1号艇が「1〜2着候補」なら1号艇。そうでなければ「★1着候補」の艇、それもいなければ総合1位の艇。
- 穴目の頭：本線の頭と1号艇以外で、「★1着候補」の艇。いなければ、その中で総合順位がいちばん上の艇。

| | 4点ずつ | 8点ずつ |
|---|---|---|
| 本線 | 1着1艇・2着2艇・3着3艇 | 1着1艇・2着3艇・3着4艇（いちばん下の1点を除く） |
| 穴目 | 1着1艇・2着2艇・3着3艇 | 穴目の頭と次の上位艇の1・2着裏表、3着は残り全艇 |

穴目の中で本線と同じ組み合わせは、点線で表示します。

### 買い判定

10/17〜10/24の全場1,248レースで、本線・穴目の的中率と回収率（1点100円）を集計しました。前半（10/21〜24）と後半（10/17〜20）の両方で同じ傾向になった条件から決めています。

| レースの種類 | 本線 4点 | 本線 8点 | 穴目 4点 | 穴目 8点 |
|---|---|---|---|---|
| 1号艇が頭・7点以下（650R） | ◎買い 的中28%・回収93% | ◎買い 的中44%・回収84% | 見送り 回収64% | 見送り 回収62% |
| 1号艇が頭・8〜11点（460R） | 見送り 的中17%・回収60% | 見送り 的中26%・回収58% | 遊び枠 | 遊び枠 |
| 1号艇が12点以上（138R） | △参考 回収196%（ばらつき大） | ○狙い 的中20%・回収152% | 遊び枠 | 遊び枠 |

穴目の「遊び枠」（1号艇8点以上・598R）は、4点で的中8%・回収72%、8点で的中15%・回収98%です。3連単は高配当で回収率が大きく動くので、目安として使ってください。

## 「ST上位」の目印（初期設定はオフ）

消し候補の2〜6号艇のうち、平均STが1〜3位の艇に、平均STの欄で「ST上位」の目印を出せます。
`app.py` の上の方にある `SHOW_ST_MARK = False` を `True` に変えると表示されます。

なお、10/21〜10/24の648レースでは、消し候補（2〜6号艇・12点以上）のうちST1〜3位の艇の2着率は8.3%で、ST4〜6位の艇（9.9%）とほぼ同じでした。

## 注意

- BOAT RACE公式サイトのデータを読みに行く個人用のツールです。公式サイトの仕様が変わると動かなくなることがあります。
- 公式サイトは1回の応答に数秒〜10秒ほどかかるため、出走表・成績データはまとめて同時に取得し、取得済みの成績データは保存して使い回します。ランキングが出るまでの目安は、初回20秒ほど、2回目以降10秒ほどです。
- 出走表が公開される前のレース（翌日以降）は計算できません。
