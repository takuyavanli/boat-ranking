# 得点率・STランキング

日付・会場・レース番号を選ぶと、出走6艇を「得点率」と「平均ST」で並べて表示するアプリです。

表示される内容は次のとおりです。

- 総合順位（得点率の順位とSTの順位の合計。「得点率を2倍重視」にも切り替えられます）
- 得点率（今節・前節・合算と、それぞれの着順）
- 平均ST（今節・前節）
- レースが終わっていれば、その結果（3連単と払戻金）

## ファイル

| ファイル | 役割 |
|---|---|
| `app.py` | 画面（Streamlit） |
| `boat_core.py` | データの取得と計算 |
| `lzh.py` | 公式データ（LZH形式）の解凍 |
| `requirements.txt` | 必要なライブラリ |

## 使い方A：スマホからいつでも使う（無料のStreamlit Community Cloud）

PCで一度設定すれば、あとはスマホのブラウザから開くだけで使えます。

1. GitHub（github.com）でアカウントを作り、新しいリポジトリを作ります（名前は例：`boat-ranking`）。
2. このフォルダの中身（上の5ファイル）をリポジトリにアップロードします。
3. share.streamlit.io を開き、GitHubアカウントでログインします。
4. 「Create app」から、作ったリポジトリと `app.py` を選びます。
5. 「Deploy」を押します。
6. 数分で専用のURLが発行されます。スマホでそのURLを開き、ホーム画面に追加しておくと便利です。

コードを書き換えてGitHubに上げ直すと、アプリも自動で更新されます。

## 使い方B：自分のPCだけで使う

1. Python をインストールします（python.org の最新版でOK）。
2. このフォルダでターミナル（Windowsはコマンドプロンプト）を開き、次を実行します。

```
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

（Windowsでは `python3` を `python` に置き換えてください）

3. ブラウザが自動で開きます。開かない場合は、表示された `Local URL`（http://localhost:8501）を開いてください。

同じWi-Fiにつながったスマホからは、表示された `Network URL` を開くと使えます。

## 計算のルール

- 着順点は 1着10・2着8・3着6・4着4・5着2・6着1 です。
- 転覆・落水・失格・F・L は0点で走数に含め、欠場は走数から除きます。
- 今節は、選んだレースより前に終わったレースだけを使います。
- 前節は、今節の初日より前で最後に走った節です（公式の日別競走成績データから自動で探します）。
- 平均STは F・L・欠場を除いて計算し、小数第2位で四捨五入して表示します。順位も表示と同じ桁で付けるので、表示が同じ数字なら同順位です。
- 総合順位は「得点率の順位＋STの順位」が小さい順です。「得点率を2倍重視」では「得点率の順位×2＋STの順位」で並べます。同点の場合は、得点率が上の選手を上にします。

## 注意

- BOAT RACE公式サイトのデータを読みに行く個人用のツールです。公式サイトの仕様が変わると動かなくなることがあります。
- 前節を探すとき、日別の成績データを最大60日分さかのぼって取得します。初回は数十秒かかることがありますが、同じ日のデータは2回目から速くなります。
- 出走表が公開される前のレース（翌日以降）は計算できません。
