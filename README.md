# ボートレースDX

日付・会場・レースを選ぶと、出走6艇を「得点率」「平均ST」「コース別3連対率」で並べて表示するアプリです。

表示される内容は次のとおりです。

- ベスト6点（過去レースでよく出た並びから選ぶ3連単6点）と、各組み合わせのオッズ・トリガミ警告
- マイ買い目（コース別成績の表の順位で組む3連単15点。「マイ買い目（15点）も見る」を開くと表示）
- 1日まとめ（その日・その会場の全レースの判定・的中・回収率）
- 総合順位（得点率・平均ST・コース別3連対率の順位の合計。直前情報が出たあとは展示タイムの順位×0.5も足す）と着順の目安ラベル、コースAI評価（S〜D）、攻めの目印
- 直前情報（進入・展示タイム・展示ST・攻めの目印）
- 「合計点の見方」の表
- 得点率（今節・前節・合算と、それぞれの着順）
- 平均ST（今節・前節）
- コース別成績（AI評価・3連対率・2連対率・1着率）
- レース結果（「結果を見る」を押したときだけ表示）

各項目の1〜3位は、1位を赤、2位を黄、3位を緑で色分けしています。

## ファイル

| ファイル | 役割 |
|---|---|
| `app.py` | 画面（Streamlit） |
| `boat_core.py` | データの取得と計算 |
| `lzh.py` | 公式データ（LZH形式）の解凍 |
| `requirements.txt` | 必要なライブラリ |
| `README.md` | この説明 |
| `.streamlit/config.toml` | 画面の色の設定（iPhoneのダークモードでも白・水色のまま表示） |

`.streamlit` は名前が「.」で始まるので、MacのFinderでは表示されません。

## 使い方A：スマホからいつでも使う（無料のStreamlit Community Cloud）

詳しい手順は「ボートレースDX_Mac手順.pdf」にあります。

1. GitHub（github.com）でアカウントを作り、リポジトリ `boat-ranking` を作ります（Public）。
2. 上の表のうち、`.streamlit` 以外の5ファイルをアップロードします。
3. GitHubの「Add file」→「Create new file」で `.streamlit/config.toml` を作り、`config.toml` の中身を貼り付けます。
4. share.streamlit.io にGitHubでサインインし、GitHubアカウントをつなぎます。
5. 「Create app」で、Repository に `ユーザー名/boat-ranking`、Main file path に `app.py` を指定して「Deploy」を押します。
6. 発行されたURLをスマホで開き、ホーム画面に追加します。

## 使い方B：自分のMacだけで使う

1. Python をインストールします（python.org の最新版でOK）。
2. このフォルダでターミナルを開き、次を実行します。

```
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

3. ブラウザが開きます。開かない場合は http://localhost:8501 を開いてください。

## 計算のルール

- 着順点は 1着10・2着8・3着6・4着4・5着2・6着1 です。
- 転覆・落水・失格・F・L は0点で走数に含め、欠場は走数から除きます。
- 今節は、選んだレースより前に終わったレースだけを使います。
- 前節は、今節の初日より前で最後に走った節です（公式の日別競走成績データから自動で探します）。
- 平均STは F・L・欠場を除いて計算し、小数第2位で四捨五入して表示します。順位も表示と同じ桁で付けるので、表示が同じ数字なら同順位です。
- コース別3連対率は、今回の枠番と同じコースでの成績です。前付けなどで枠とコースが変わった場合は反映されません。また、過去の日付のレースを選んだときも、今の時点の数字を使います。
- 総合順位は「得点率の順位＋STの順位＋コースの順位」が小さい順です。同点の場合は、得点率が上の選手を上にします。

## オッズとトリガミ警告

買い目の各組み合わせの右に、公式サイトの3連単オッズを表示します。「🔄 オッズを更新」ボタンで最新のオッズに取り直せます（何もしなくても1分たつと取り直します）。オッズが15倍未満（マイ買い目の点数未満）の組み合わせは赤く表示します。当たっても買った金額を下回る組み合わせなので、外して買う目安にしてください。

## 1日まとめ

日付と会場を選んで「この日・この会場をまとめて見る」を押すと、全レースのマイ買い目の判定（向いている／不向き）・的中・結果・払戻を一覧にします。上に、次の2つの回収率も出ます（1点100円）。

- 「向いている」レースだけ買った場合
- 全レース買った場合

全レースのデータを集めるので、30秒ほどかかります。まだ終わっていないレースは「-」になり、回収率には入りません。

## コースAI評価（S〜D）

その選手の今回のコースでの3連対率と2連対率の平均を、同じコースを走る選手全体（10/17〜10/24の出走データ）と比べて判定します。

| 評価 | 表示 | 位置 |
|---|---|---|
| S | 得意 | 上位10% |
| A | 良い | 上位30% |
| B | 普通 | 中間 |
| C | やや苦手 | 下位30% |
| D | 苦手 | 下位10% |

コースごとに基準を分けています（例：Sの下限は1コース92.6%、6コース45.5%）。評価が高いほど実際の着順も良く、8日分では1号艇の1着率がSで73%、Dで25%でした。総合順位の合計点には、評価ではなくコース3連対率の順位を使います。

## 目安ラベルの決め方

10/17〜10/24の全場1,248レースで、合計点（3項目を同じ重み・3〜18点）と実際の着順を集計した結果から決めています。

| ラベル | 1号艇 | 2〜6号艇 |
|---|---|---|
| 1〜2着候補 | 11点以下（1着56%・3連対84%） | — |
| 2〜3着候補 | 12〜16点（1着29%・3連対63%） | 7点以下（1着21%・3連対68%） |
| 3着候補 | — | 8〜11点（1着10%・3連対49%） |
| 消し候補 | 17点以上 | 12点以上（3連対27%） |


### ★1着候補（まくり型）

2〜4号艇で、平均ST（今節＋前節）が内側の艇全員より0.02秒以上早く、合計点（同じ重み）が7点以下の艇です。上の表より優先して「★1着候補」と表示します。8日分で1着28%・2連対56%・3連対72%でした（2〜6号艇全体は1着9%）。この艇がいるレースでは、1号艇の1着率が57%から43%に下がります。

### 試して採用しなかったもの

- 当地勝率・当地2連対率を順位に入れる：上位3艇ボックス的中は21.1%→21.7%（当地2連対率）と差が小さく、期間によって良くなったり悪くなったりしたため見送り。今節がその場での成績なので、当地の調子はすでに入っていると考えられます。
- 今節・前節の展示タイム（各レースでの展示順位の平均）を順位に入れる：ボックス的中21.2%→20.0%、総合1位の1着率38.5%→36.6%と、前半・後半とも下がったため見送り（当日の展示タイムは採用）。

- モーター2連対率（今節＋前節、今節のみ、期間通算）を順位に入れる：どの形でも、入れない方がわずかに当たりやすかったため外しました（総合上位3艇のボックス的中 21.2% → 19.0%）。
- コース成績を2連対率で順位に入れる：3連対率の方が、本線「買い」の回収率が高かったため（4点で92% 対 80%）、順位には3連対率を使い、2連対率は表に参考として出しています。

## 直前情報と攻めの目印

締切の30分前ごろに公式サイトに出る直前情報（展示タイム・スタート展示）を取り込みます。出たあとに「🔄 オッズ・直前情報を更新」を押すと反映されます。

- 総合順位：3つの順位に「展示タイムの順位×0.5」を足して並べます。10/17〜10/24の1,231レースで、総合1位の1着率が38.7%→40.3%、上位3艇ボックスの的中が21.4%→22.3%になりました（前半・後半とも改善）。展示STの順位をそのまま足すと悪くなるため、展示STは目印にだけ使います。
- 目安ラベル・★1着候補・ベスト6点は、展示を入れない3項目で判定します（ベスト6点に展示を入れると回収が下がったため）。

| 目印 | 条件 | 1着率 |
|---|---|---|
| まくり注意 | 3・4コースで、展示STが内側の全艇より0.05秒以上速く、展示タイム3番目以内 | 19%（通常12%） |
| 差し注意 | 2コースで、展示タイム1〜2番目、3コースの展示STが1コースより0.03秒以上速い | 22%（通常15%） |
| まくり差し注意 | 3・4コースで、すぐ内より0.03秒以上速く（内側全艇より0.05秒以上ではない）、展示タイム1〜2番目 | 16%（通常12%） |
| 1号艇注意 | 1コースの展示タイムが5〜6番目 | 40%（通常53%） |

攻めの目印が付く艇がいるレースでは、1コースの1着率が56%から49%に下がりました。展示STが平均STより速いかどうかは、結果とほぼ関係がありませんでした。

## ベスト6点（3連単）

10/17〜10/24の全場1,248レースで、結果の3連単を「何位-何位-何位」に置き換えて、よく出る並びを調べました。前半（10/21〜24）で選んだ並びが後半（10/17〜20）でも当たるか、その逆も確かめ、両方の期間で当たった形を使っています。

| レースの種類 | 6点の組み方 | 的中率 | 回収率 |
|---|---|---|---|
| 1号艇が7点以下（1号艇が強い） | 1号艇が頭、2・3着は総合順位の上位3艇（1号艇を除く） | 36% | 89%（前半92%・後半86%） |
| 1号艇が8点以上（1号艇が弱め） | コース別成績の表の順位で 1-2-3・1-2-4・1-3-2・1-2-5・1-4-2・2-1-3 | 25% | 91%（前半95%・後半86%） |
| 全体 | | 31% | 90%（前半93%・後半86%） |

6倍未満の組み合わせは赤く表示します（6点買うと当たっても赤字）。6点に絞っているので、外枠が絡む中穴は拾いにくくなります。

## マイ買い目（3連単15点）

コース別成績の表の順位（3連対率の高い順、同じ数字なら枠番の若い順）で組みます。表の1位と3位、2位と4位を組にして、6位は消しです。

| 行 | 1着 | 2着 | 3着 |
|---|---|---|---|
| 1 | 1位 | 3位 | 2・4・5位 |
| 2 | 3位 | 1位 | 2・4・5位 |
| 3 | 2・4・5位 | 3位 | 1位 |
| 4 | 4位 | 2位 | 1・3・5位 |
| 5 | 1・3・5位 | 2位 | 4位 |

10/17〜10/24の全場1,248レースでは、的中26%・回収75%でした。1号艇がコース表の1〜2位のレースは「向いている」（的中26%・回収79%）、3位以下のレースは「不向き」（的中22%・回収38%）と表示します。行ごとでは「1位-3位」の行が当たりの中心（134回・平均1,832円）で、「4位-2位」の行はめったに来ないものの平均1万8千円の大物でした。

以前あった「本線・穴目」の買い目と点数の切り替え、総合順位の重みの切り替えは外しました。

## 「ST上位」の目印（初期設定はオフ）

消し候補の2〜6号艇のうち、平均STが1〜3位の艇に、平均STの欄で「ST上位」の目印を出せます。
`app.py` の上の方にある `SHOW_ST_MARK = False` を `True` に変えると表示されます。

なお、10/21〜10/24の648レースでは、消し候補（2〜6号艇・12点以上）のうちST1〜3位の艇の2着率は8.3%で、ST4〜6位の艇（9.9%）とほぼ同じでした。

## 注意

- BOAT RACE公式サイトのデータを読みに行く個人用のツールです。公式サイトの仕様が変わると動かなくなることがあります。
- 公式サイトは、海外のサーバー（Streamlit Community Cloud）からだと1回の応答に数秒〜10秒ほどかかります。待ち時間を減らすため、次のように裏で先読みしています。
  - アプリを開いたら、開催場の一覧と直近の成績データを裏で取り始めます。画面はすぐ出て、開催場の一覧は届きしだい自動で切り替わります。
  - 会場を選んだら、その日の全レースの出走表と選手のコース別成績をまとめて取り、全レースを裏で計算しておきます。
  - レースを選んだら、そのレースを最優先で計算します。
  - 一度計算したレースは覚えておくので、同じ会場の別のレースはすぐ出ます（今日のレースは5分ごとに計算し直します）。
- Streamlit Community Cloud の無料版は、しばらく使わないとアプリが休止し、次に開いたときの起動に30秒〜1分ほどかかります。
- 出走表が公開される前のレース（翌日以降）は計算できません。
